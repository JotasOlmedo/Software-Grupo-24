📊 Diagrama de Base de Datos - Sistema de Gestión de Cilindros

nombre VARCHAR(100)
apellido VARCHAR(100)
correo VARCHAR(100) UNIQUE
rut VARCHAR(20) UNIQUE
contraseña VARCHAR(100)
rol_id INTEGER (FK)
🔐 ROL
id INTEGER (PK)

permisos TEXT[]
🛢️ CILINDRO

👥 CLIENTE
id_cliente INTEGER (PK)

📋 PEDIDO
id_pedido INTEGER (PK)

🔗 Relaciones Principales
Usuario → Rol: usuario.rol_id → rol.id (Muchos a Uno)
Pedido → Cliente: pedido.cliente_id → cliente.id_cliente (Muchos a Uno)
Pedido → Chofer: pedido.chofer_id → chofer.id (Muchos a Uno)
DetallePedido → Pedido: detallepedido.id_pedido → pedido.id_pedido (Muchos a Uno)
DetallePedido → Cilindro: detallepedido.id_cilindro → cilindro.id (Muchos a Uno)
Despacho → Pedido: despacho.pedido_id → pedido.id_pedido (Uno a Uno)
Despacho → Vehiculo: despacho.vehiculo_id → vehiculo.id_transporte (Muchos a Uno)
Despacho → Ruta: despacho.ruta_id → ruta.id_ruta (Muchos a Uno)
Perdida → Cilindro: perdida.id_cilindro → cilindro.id (Muchos a Uno)
Perdida → Usuario: perdida.id_usuario → usuario.id (Muchos a Uno)
InventarioCilindros → Inventario: inventariocilindros.inventario_id → inventario.id (Muchos a Uno)
InventarioCilindros → Cilindro: inventariocilindros.cilindro_id → cilindro.id (Muchos a Uno)
Reporte → Usuario: reporte.usuario_id → usuario.id (Muchos a Uno)
ResetToken → Usuario: resettoken.usuario_id → usuario.id (Muchos a Uno)
Administrador → Usuario: administrador.id → usuario.id (Uno a Uno)
JefeDeBodega → Usuario: jefedebodega.id → usuario.id (Uno a Uno)
Chofer → Usuario: chofer.id → usuario.id (Uno a Uno)
